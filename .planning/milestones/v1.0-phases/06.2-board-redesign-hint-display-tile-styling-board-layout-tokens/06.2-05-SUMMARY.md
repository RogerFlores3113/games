# Phase 06.2 Plan 05: Token Art, Token Column, and Fanned Played Stack Summary

**Four standalone, independently render-tested components — clue/fuse token SVG art, a height-bounded shrinking token column, and a horizontally-fanned played stack — built and verified in isolation ahead of the Table.tsx layout rework that will consume them.**

## Performance

- **Duration:** ~25 min
- **Completed:** 2026-09-17T14:39:42Z
- **Tasks:** 3 completed
- **Files modified:** 6 (all created)

## Accomplishments

- `ClueTokenArt.tsx` / `FuseTokenArt.tsx`: inline SVG, token-only colours (`--color-token-disc`, `--color-suit-blue`, `--color-suit-yellow`, `--color-token-fuse-rim`), `aria-hidden`/`focusable="false"`, no hex literals, no id collisions across multiple instances.
- `TokenColumn.tsx`: renders exactly the remaining clue/fuse tokens (spent tokens absent from the DOM, never dimmed), with `data-count` on the `clue-tokens`/`fuse-tokens` testid elements and always-present "{n} clues left"/"{n} fuses left" text. Disc size is derived from the supplied `columnHeightPx` via `tokenPitchPx`, clamped only downward (never up), so the column's total rendered height provably never exceeds its budget even at `MAX_TOKEN_COUNT` (11).
- `PlayedStack.tsx`: renders every card from rank 1 to `topRank`, each offset horizontally by `FAN_PEEK_PX` and layered with increasing z-index so the top rank sits frontmost. Row height stays fixed at `PLAYED_CARD_HEIGHT_PX` regardless of card count; width follows `fannedStackWidth(topRank)`. Preserves the existing `played-stack-{suit}` testid, `data-top-rank`, `data-complete`, the completed-stack glow, the empty-state `SuitGlyph` placeholder, and the `sr-only` suit name; adds per-card `played-stack-{suit}-card-{rank}` testids.
- All three components/pairs followed full RED → GREEN TDD, and the whole monorepo (69 files / 806 tests) plus `tsc -b` across all four packages passed clean after the final task.

## Decisions Made

- Fuse explosion art is hand-authored locally (not via `suit-visuals.ts`'s private star-burst helpers) with a 9-spike/3-radius-cycle silhouette, guaranteed distinct from every `SUIT_VISUALS` entry's silhouette space.
- `TokenColumn`'s disc-size clamp is one-sided (`Math.min` against a max, `Math.max` against a small legibility floor) so the height-budget invariant that `tokenPitchPx` already guarantees can never be broken by the clamp itself.
- `PlayedStack`'s empty-state box reserves `PLAYED_CARD_WIDTH_PX` rather than `fannedStackWidth(0)` (which is 0 by design in `layout-budget.ts`), so the empty-stack placeholder still has a visible box.
