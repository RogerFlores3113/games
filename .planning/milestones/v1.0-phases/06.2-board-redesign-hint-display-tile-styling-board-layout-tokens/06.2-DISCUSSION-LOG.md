## Scout findings that shaped the decisions

A codebase scout ran before the decisions. The findings that mattered most:

- The 1280x720 no-scroll fit rests on scattered constants with no single budget. This phase adds height in several places, so the fit needs to be a first-class task. Removing the 28px pip band frees the room the note box and token art then spend.
- `own-hand-source.test.ts` scans a hand-maintained file list for identity leaks. New own-hand components must be added to it explicitly.
- The `reorder` action from 06.1-01 is a complete worked example for `reorderDiscard`, including the actionId dedup that sits before the status gate.
- Transient highlights must use refs rather than effect cleanup, because `game` is a new object on every server frame.
