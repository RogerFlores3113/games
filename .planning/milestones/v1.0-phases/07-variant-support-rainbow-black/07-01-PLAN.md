Add a dedicated legality reason, thread it through the three closed-union sites, correct the misleading `isClueRequest` doc comment, and prove the fix with per-variant regression tests at the engine, adapter and worker layers plus a property test.

Output: patched `canClue`, the `clue_color_not_nameable` reason threaded rules to schema to worker, regression tests in all three layers, `nameable-colour.property.test.ts`.
</objective>
