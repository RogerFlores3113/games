| Boundary | Description |
|----------|-------------|
| RoomState (server-only, includes seed and full game) -> RoomView | toSeatView + adapter.toPlayerView reduce to one seat |
| RoomView -> encoded frame | Last in-memory checkpoint before bytes leave the Durable Object |
| persisted storage from previous deploy -> current adapter | Stale counter-shaped game state could reach the toy adapter |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-09 | Information Disclosure | seat-projection.ts validateGameView | mitigate | Strict ForeheadCardViewSchema.safeParse on every projected game view; failure returns null (fail closed, D-07); caller can never obtain the raw view from this module |
| T-02-10 | Information Disclosure | console.error in the fail-closed branch | mitigate | Log only seatId plus issue code/path; test asserts the logged arguments contain neither the leaked value nor the seed |
| T-02-11 | Tampering / Denial of Service | persisted adapterId counter rooms after deploy | mitigate | ROOM_SCHEMA_VERSION bumped to 2; loadRoom's existing mismatch path resets without reading the blob; persistence test proves it |
| T-02-12 | Elevation of Privilege (architectural erosion) | game-specific imports spreading into generic worker code | mitigate | game-registration.ts is the single registration point; acceptance grep asserts no other non-test worker file names the game; Plan 04's structural test enforces it permanently |
| T-02-13 | Information Disclosure | seed / undealt deck on the wire | mitigate | Layer-2 property checks seed and every undealt value against every encoded frame (D-14) |
