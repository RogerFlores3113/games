## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| store view -> rendered UI | Client renders server-provided, already-redacted views; no new data crosses |
| user click -> socket send | UI actions gated while the connection is degraded |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-16 | Tampering | actions against a stale view during reconnect | mitigate | all controls `disabled` while reconnecting, HanabiBoard `act()` guard, RoomClient `send()` guard, plus 05-03 maxEnqueuedMessages: 0; server stays authoritative |
| T-05-17 | Denial of Service | double-click on Use this tab firing repeated reconnects | mitigate | `reclaiming` state disables the button after the first click until status leaves superseded |
| T-05-18 | Information Disclosure | per-seat status rendering | accept | `connected` is already in every seat's view (Phase 1 lobby shows it); display only |
| T-05-19 | Repudiation | misleading "disconnected" alarm for a seat missing from view | mitigate | isSeatConnected defaults unknown seats to connected; muted slate token, never destructive red (UI-SPEC) |
</threat_model>
