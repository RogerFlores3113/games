Locked design (planner decisions within Claude's discretion):
- Grid-aligned sweep: dueAt = (Math.floor(now / intervalMs) + 1) * intervalMs. Stable for every call inside the same interval window, so #commit on every action cannot push it forward (Pitfall 3); worst-case detection = staleMs + intervalMs.
- lastSeenAt = max(autoResponseTimestamp?.getTime() ?? 0, attachment.boundAt ?? 0). `boundAt` (ms epoch) is written into the attachment at join so a just-joined socket that has not pinged yet is not reaped. A pre-Phase-5 attachment without boundAt and no pings counts as 0 -> stale -> closed with a NON-terminal code -> the client reconnects (accepted deploy-transition behavior).
- Env override parsing: a string that parses to a finite integer >= 500 wins; anything else (undefined, "", "abc", "0", "-5", "12.5") falls back to the schema constant. Production never sets these vars.
