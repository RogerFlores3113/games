Implement the turn engine: hostile-input request guards, the play, discard and clue branches with their token and fuse arithmetic, the explicit final-round counter, and the three end conditions with score and descriptive band.

Output: `actions.ts` and `endgame.ts` with example-based tests carrying the specific rules.
</objective>

scale proportionally from the published 25-point table (RESEARCH.md assumption A2):
  score === 0            -> "Oh no!"
  score === maxScore     -> "Legendary"
  ratio < 0.24           -> "Horrible"
  ratio < 0.44           -> "Poor"
  ratio < 0.64           -> "Decent"
  ratio < 0.84           -> "Excellent"
