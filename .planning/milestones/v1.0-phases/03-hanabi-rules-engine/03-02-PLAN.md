<objective>
Build the three pure, side-effect-free modules that `applyAction` will compose in plan 03: the typed legality predicates (which Phase 6's UI will call to disable illegal actions without trial-and-error), the clue-fact candidate-set narrowing (the product's sole memory aid), and the public-facts-only turn history.

Purpose: D-13 requires legality to be queryable without attempting the action, and D-06 requires clue facts to be engine state rather than something the UI derives. Keeping all three out of `actions.ts` keeps that module small enough to review and makes every rule independently testable.
Output: `history.ts`, `clue-facts.ts`, `legality.ts` with unit tests across all three variants, plus a widened `AdapterError` union.
</objective>
