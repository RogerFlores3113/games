<objective>
Close UAT gaps 4, 5 and 6, and the token half of gap 1: give clue tokens a blue outline, double the token size, remove the on-screen count text, and make the token area a fixed reserved grid that does not change size as tokens are spent.

Purpose: the owner asked for "the clues have a blue outline like the fuses do", tokens "larger by 2x", and removal of the "obtrusive text saying 'X fuses left' and 'X clues left'" — while gap 1 requires the area to reserve its space up front. Doubling the disc size cannot be done by growing the column: at eleven tokens a 40px disc in one vertical run is 484px tall against a ~244px budget, so the run has to become a fixed grid instead.
Output: an outlined clue token, a 40px disc, an accessible-only count, and a token area whose rendered height and width are constants.
</objective>
