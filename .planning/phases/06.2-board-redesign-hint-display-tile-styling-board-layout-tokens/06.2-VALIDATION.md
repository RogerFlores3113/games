# Phase 06.2 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Derived from `06.2-RESEARCH.md` §Validation Architecture.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest 4.x (unit + render), Playwright (e2e), fast-check (property) |
| **Config file** | `apps/web/vitest.config.ts` (web project), `playwright.config.ts` at repo root |
| **Quick run command** | `npx vitest run --project web <name-fragment>` |
| **Full suite command** | `npm test && npx playwright test && npx tsc -b apps/web packages/rules packages/schema apps/worker` |
| **Estimated runtime** | ~90s Vitest, ~3min Playwright |

---

## Sampling Rate

- **After every task commit:** targeted Vitest run for the files touched
- **After every plan wave:** `npm test` plus `npx tsc -b apps/web packages/rules packages/schema apps/worker`
- **Before `/gsd:verify-work`:** full suite green, plus a manual 1280x720 no-scroll check with a 5-seat Rainbow or Black game (worst-case content volume)
- **Max feedback latency:** ~90 seconds
