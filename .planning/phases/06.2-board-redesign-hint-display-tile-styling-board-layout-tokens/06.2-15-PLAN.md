<objective>
Close UAT gap 3 and the play-area half of gap 1: replace the horizontal fan with a grid where each suit is a column and ranks fill top to bottom, with all five rank slots reserved whether or not they hold a card.

Purpose: the owner's verbatim instruction — "For the play area - it should be filling up rows. So each color is either a column or a row, and the next entries in the series go directly below or to the right of the tiles, creating a grid" — and the follow-up answer: suits as COLUMNS, ranks filling top to bottom. This replaces BOARD-05's horizontal fan (D-22). Height is the scarce dimension at 1280x720, so the column grid must fit inside the reserved play area rather than growing it.
Output: a fixed play-grid geometry in the ledger, and `PlayedStack` rewritten as a five-slot suit column.
</objective>

The geometry this plan must hit, derived from the measured board rather than chosen freely (see `deferred-items.md` for the measurement history — the UI-11 fit currently passes at exactly 720px with zero slack, after a regression that cost this phase a day):

- The tableau band's ledger budget is `TABLE_BAND_MIN_PX = 260`. The board panel's own padding is `--space-sm` (8px) on each side plus a 1px border, so the three board regions share an inner height of `260 - 16 = 244`.

- Six suits (the Rainbow/Black worst case) at 30px wide with 4px gaps plus 8px padding is 208px wide. Page width is the cheap axis at 1280px.

Current `PlayedStack.tsx` contract that must be preserved for the drag system and the e2e suite: the root element keeps `data-testid={"played-stack-" + suit}`, `data-top-rank`, `data-complete`, the completed-stack `anim-stack-flash` class driven by the `flashing` prop, and the `played-stack-{suit}-card-{rank}` testids for filled ranks.

Glyph-count invariant (`e2e/start-game.spec.ts` ~line 421): `expect(stack.locator("[data-glyph]")).toHaveCount(1)` for every played stack. `FireworkCardFace` emits `data-glyph` only when given `exposeSuit`. Keep exactly one glyph per column by putting the suit's `SuitGlyph` in a single column header and rendering filled rank cards WITHOUT `exposeSuit`, with an `sr-only` "{Suit} {rank}" span per filled slot for the accessible name (the same pattern `Table.tsx` already uses for discard tiles).
