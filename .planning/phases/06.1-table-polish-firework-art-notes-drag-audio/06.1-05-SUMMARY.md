# Phase 06.1 Plan 05: City-at-Night Table Backdrop Summary

Sourced a license-verified city-at-night photo from Wikimedia Commons, optimized it to a 268 KB WebP, and wired it behind the in-game table via a `.table-backdrop` CSS class with a 75%-opacity `--color-bg` scrim, replacing the flat background fill without changing card/text contrast.

## What Was Built

**Task 1 — Sourced, license-verified, and optimized the background image.**
Unsplash and Pexels both blocked scripted `curl` requests with bot-challenge pages (Anubis on Unsplash, Cloudflare managed challenge on Pexels), so neither site's photo or license page could be genuinely fetched and verified this session — per the plan's explicit instruction, no unverified image was used. Wikimedia Commons was used instead: its API returns structured, directly-verifiable `imageinfo`/`extmetadata` (license, author, attribution requirement) without a bot wall, and D-14 names Unsplash/Pexels as examples ("e.g."), not an exclusive list. Selected `DFC 4635 Pattaya lights sparkle under a clear night sky…` — a dark, elevated-viewpoint night skyline with sky space, no readable text, no identifiable people — licensed CC BY-SA 4.0 by Flickr user PattayaPatrol, confirmed via `action=query&prop=imageinfo&iiprop=extmetadata` against the Commons file page. Downloaded the original (5568×3712 JPEG), resized to 1920px wide with PIL/LANCZOS, and re-encoded as WebP at quality 80 (268,138 bytes, under the 300 KB cap). Wrote `apps/web/public/backgrounds/CREDITS.md` with Source URL, Author, Author URL, License, License URL, a verbatim-quoted grant sentence from the CC BY-SA 4.0 deed page, retrieval date, and modifications.

**Task 2 — Applied the backdrop with scrim to the in-game table (TDD).**
Wrote `apps/web/lib/background-asset.test.ts` first (RED confirmed: the `.table-backdrop` assertion failed while the asset/credits assertions already passed since Task 1's files existed). Added `.table-backdrop` to `globals.css` (outside `@theme`, no hex literal) with `background-color: var(--color-bg)`, `background-image: linear-gradient(rgba(11, 15, 26, 0.75), rgba(11, 15, 26, 0.75)), url("/backgrounds/city-night.webp")`, `background-size: cover`, `background-position: center`, `background-attachment: fixed` (static per D-14 — no parallax/scroll). Replaced the in-game `<main>`'s inline `backgroundColor` style in `HanabiBoard.tsx` with the `table-backdrop` className; the loading/error `<main>` was left unchanged per the plan's interface note. Confirmed GREEN.

### Auto-fixed Issues

**1. [Rule 3 - Blocking issue] Unsplash/Pexels unreachable for license verification**
- **Found during:** Task 1
- **Issue:** Both `unsplash.com` and `pexels.com` return bot-challenge HTML (Anubis proof-of-work challenge on Unsplash, Cloudflare managed challenge on Pexels) to scripted `curl` requests, even with a browser-like User-Agent — no photo page or license page could be genuinely fetched and read this session.
- **Fix:** Used Wikimedia Commons instead, which serves a public JSON API (`action=query&prop=imageinfo&iiprop=extmetadata`) returning license name, license URL, author, and attribution-required flag directly — verified without a bot wall. D-14 names Unsplash/Pexels as examples ("e.g."), and Commons is an equally clearly-free-license source with machine-verifiable metadata.
- **Files modified:** apps/web/public/backgrounds/city-night.webp, apps/web/public/backgrounds/CREDITS.md
