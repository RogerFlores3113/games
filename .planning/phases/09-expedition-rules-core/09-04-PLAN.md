<objective>
Build the camp state machine's setup and derived-state layer, and the CoreRules hook seam it runs through. createCamp deals, finds the leader, flips objectives; campPhase/currentActorSeatId/checkCampOutcome derive everything else from state.

Purpose: wires XRULE-04 (leader picks first, leads first), XRULE-05 (objectives flipped from the second deck), XRULE-01 (removed cards + hand size recorded in camp state), XRULE-07 (camp outcome: succeed when all done, fail when any failed or a failure check fires).
Output: rules.ts, camp.ts, camp.test.ts. Plan 05 adds actions and legality on top.

Hook seam scope (spec §6.1): Phase 9 defines the CoreRules type with only the hooks the Core layer itself calls — deckFor, leaderFor, isTrump, trickWinner, legalPlays, nextLeader, failureChecks — and a baseRules implementation. The layering/composition mechanism (base → boss twist → gear, each hook receiving the previous layer's answer), and the whisper/objectiveAssignment/capacity/failureCost hooks, are Phase 10. Every core function takes `rules: CoreRules = baseRules` as its LAST parameter so Phase 10 passes a composed rule set without changing any call signature.
</objective>
