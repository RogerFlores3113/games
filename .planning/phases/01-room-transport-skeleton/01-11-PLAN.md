<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet → production Worker | Any origin can attempt a WebSocket handshake against the deployed `*.workers.dev` host |
| registrar DNS → games.rogerflores.dev | Control of the DNS record is control of the product's entire entry point |
| provider billing terms → availability | A plan change or an unnoticed trial expiry silently breaks the core "click a link on a random Tuesday" promise |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-05 | Information Disclosure | production WebSocket Origin | mitigate | Task 2 adds `https://games.rogerflores.dev` to the `onConnect` allowlist and redeploys, so a random cross-origin page cannot open a socket from a browser. A non-browser client can forge `Origin`; per-seat projection remains the real confidentiality control, so this is defense in depth (RESEARCH Pitfall 7, assumption A2). |
| T-1-29 | Spoofing | DNS / domain takeover | accept | The registrar account for `rogerflores.dev` is the trust root for the entire product. No technical control in this repo can mitigate it; account hygiene at the registrar is the control. Recorded in `custom-domain.md` so the dependency is at least written down. |
| T-1-30 | Denial of Service | free-tier limits exhausted | mitigate | FDN-03 records the Workers Free daily caps (100k req/day, 13,000 GB-s/day, 5M row reads/day, 100K row writes/day, 5GB storage) so exhaustion is diagnosable rather than mysterious. ROOM-08's idle GC bounds storage. CLAUDE.md notes the $5/month Workers Paid plan removes the caps with zero architecture change if the friend group ever outgrows Free. |
| T-1-31 | Denial of Service | provider pausing on inactivity | mitigate | This is the failure that rejected Supabase and shaped the whole stack. The cold-start procedure (Task 4) is the only evidence-producing control; `free-tier.md` additionally records an explicit check that neither dashboard shows a suspension or trial notice. |
| T-1-32 | Information Disclosure | secrets in the repo | mitigate | `NEXT_PUBLIC_WORKER_HOST` is public by construction — it is the host a browser dials. No other secret is introduced by this phase; Cloudflare and Vercel credentials live in the user's local CLI config and the providers' dashboards, and `.gitignore` covers `.env*.local` and `.vercel`. |
</threat_model>
