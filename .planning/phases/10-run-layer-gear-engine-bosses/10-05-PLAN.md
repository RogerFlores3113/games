    2. runStatus(run) and runPhase(run), per the must_haves. They are derived and never stored.

    3. nextAttemptNumber(run) = 1 + the number of history entries whose campNumber equals run.campNumber.

    4. capacityOf(run, seatId, catalog) = rulesFor(run, catalog).capacity(run, seatId).

    5. loadoutSize(gearIds, catalog): the sum of sizes. Throw on an unknown id.

    6. preDealPendingSeatIds(run, catalog): only while attempt non-null and camp null. A seat is pending if it has an equipped gear whose window is "pre-deal", that gear is not isGearSpent, and gearAvailability(...) is ok.

    7. drawBossTwist(seed, campNumber, bossIds, excludedId): string | null
       - sort the pool and remove excludedId. If the pool is empty, return null (a catalog with no eligible boss gives a camp with no twist; test catalogs may have no bosses);
       - pick pool[seededIndex(seed, STREAMS.boss(campNumber), pool.length)].

    8. startAttempt(run, catalog):
       - throw unless runPhase is fireside and every seat is ready;
       - draw bossTwists[N] only when N is in BOSS_CAMPS and it is null. Camp 6 excludes bossTwists[3] (D-03);
       - attempt = { attemptNumber: nextAttemptNumber(run), bossCancelled: false, gearUses: [], effects: [], reveals: [], log: [], camp: null };
       - readySeatIds [];
       - return advanceRun(next, catalog).

    9. dealAttempt(run, catalog):
       - rules = rulesFor(run, catalog);
       - camp = createCamp({ seatIds, seed: attemptSeed(seed, N, A), objectiveSlots: objectiveSlotsFor(seed, N, A) }, rules);
       - if rules.objectiveAssignment(run) === "face-down", camp = assignFaceDown(camp, seed, N, A).

    10. assignFaceDown(camp, seed, N, A): shuffle objective ids with STREAMS.faceDown(N, A), then give the i-th shuffled objective to seatIds[(indexOf(expeditionLeader) + i) % n].

    11. settleIfDecided(run, catalog), per the must_haves:
       - compute outcome with checkCampOutcome(camp, rulesFor(run, catalog));
       - compute cost via rules.failureCost(run) BEFORE clearing the attempt. Throw (policy A3) if a failure's cost is not an integer >= 1, because a composed hook must never make failure free;
       - supplies = Math.max(0, supplies - cost);
       - after a success below FINAL_CAMP: campNumber + 1, and each seat's draftOffer = draftOfferFor(seed, N + 1, seatId, keys, owned).

    12. advanceRun(run, catalog):
       - if runPhase is "pre-deal" and preDealPendingSeatIds is empty, dealAttempt;
       - then settleIfDecided;
       - return the result.

    Every function is pure, builds new objects, and never mutates.
