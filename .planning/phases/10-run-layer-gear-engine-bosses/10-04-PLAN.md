  <behavior>
    - move-card moves the card id from one hand to the end of the other. A missing card or from === to throws.
    - swap-cards exchanges two cards in place. A card not in the named seat's hand throws.
    - replace-objective on an unowned ordered objective:
      - keeps id, kind and order;
      - sets target to objectiveDeck[0] and drops that card from the deck.
      On an owned objective, a cardless objective or an empty deck, it throws.
    - swap-objectives("p0", "p1") swaps ownerSeatId only for objectives whose evaluateObjective is "pending". An already-"done" objective owned by p0 stays with p0 (D-10).
    - remove-objective removes the objective from camp.objectives. An unknown id throws.
    - reveal:
      - appends { cardId, fromSeatId: <holder>, audience, source: gearId };
      - an audience that is empty, contains a non-seat, or contains duplicates throws;
      - a card not in any hand throws.
    - add-modifier appends { gearId, seatId: actor, atTrick: camp.completedTricks.length } to attempt.effects.
    - set-next-leader sets camp.currentTrick.leaderSeatId. It throws if the current trick has plays or the camp is null. Before trick 1 it is allowed (D-09).
    - cancel-boss-twist sets attempt.bossCancelled true only while camp is null. With a camp dealt, it throws.
    - log appends a LogEntry with actorSeatId = actor and gearId. An audience array containing a non-seat throws.
    - Every successful op list leaves campCardIds(camp) (sorted) unchanged. Input states are never mutated: a structuredClone taken before the call deep-equals the input after it.
  </behavior>
