## Integration (no gaps)

An independent integration check (gsd-integration-checker, 2026-09-22) traced every
cross-phase export to a real caller. Every client message has a matching worker branch
and every server message a client handler. The structural invariants were confirmed to
have exactly one call site each: one `#send`, one `projectSeatView`, one `activeGame`
registration point, one alarm-arming site. No orphaned exports and no missing
connections were found.

## Flows (6/6 complete)

1. Create room → room code → host seated in lobby.
2. Second player joins by link and name → live seat list → duplicate-name suffixing.
3. Variant pick → start → per-seat filtered views.
4. Play, discard and clue (including drag, hints, notes, audio) → server validation →
   persisted state → per-seat push → UI update.
5. Reconnect: refresh, dropped socket, heartbeat-forced reconnect, superseded tab →
   "Use this tab".
6. Game end → end overlay → host restart or delete; idle 24h cleanup → abandoned-room
   message.

The Black variant was checked across all four layers (rules `SUIT_RULES`, the
direction-agnostic `playedRanks` on the wire, the worker, `PlayedStack.tsx`) and is
consistent.
